# 🐍 Snake Water Gun Game

A simple and interactive **Snake Water Gun Game** developed using **Python**. The game allows the user to play against the computer and determines the winner based on the selected choices.

## 🎮 About the Game

Snake Water Gun is a game similar to Rock Paper Scissors.

The rules are:

* 🐍 **Snake drinks Water → Snake wins**
* 💧 **Water douses Gun → Water wins**
* 🔫 **Gun kills Snake → Gun wins**
* If both players choose the same option, the game is a **Draw**.

## ✨ Features

* Simple and beginner-friendly Python project
* User vs Computer gameplay
* Random computer choice
* Displays the result of each round
* Easy-to-understand game logic

## 🧠 Game Logic

The computer randomly selects one of the three choices. The user's choice is then compared with the computer's choice according to the game rules.

### Winning Conditions

```text
Snake  → Water
Water  → Gun
Gun    → Snake
```
